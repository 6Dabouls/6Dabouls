Sécurité

Votre argent est entre de bonnes mains

Nous utilisons les technologies de sécurité les plus avancées pour protéger vos fonds et vos données personnelles.

  • Chiffrement de bout en bout — Toutes vos données sont chiffrées avec AES-256.
  • Authentification à deux facteurs — Sécurisez l'accès à votre compte avec un code SMS.
  • Notifications instantanées — Soyez alerté pour chaque transaction, autorisée ou non.
  • Blocage immédiat — Bloquez votre carte en un seul tap depuis l'application.
  • Conforme PCI DSS — Nous respectons les normes de sécurité bancaires internationales.
